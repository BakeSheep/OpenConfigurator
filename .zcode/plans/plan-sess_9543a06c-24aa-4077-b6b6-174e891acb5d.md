# SkyLab 前端 UI 完全重构为 MicoConfigurator 样式

## 目标
把当前 PX4 Web GCS 的 UI 从"近似 MicoAir 风格"重写为**与 https://micoair.com/configurator/ 视觉上一模一样**，基于已抓取到的真实 CSS 设计系统。功能逻辑（WebSocket / stores / MAVLink）**全部保留**，只改视觉层。

## 设计系统（来自真实 CSS，权威值）

### 配色（深色主题 CSS 变量）
```
--bg-primary:   #0A0A0F   ← 主背景（当前 #0f1117，更深）
--bg-secondary: #13131A   ← 顶栏/侧栏/卡片背景
--bg-tertiary:  #1C1C26   ← 输入框/次级表面
--bg-hover:     #24243A   ← 悬停
--border:       rgba(255,255,255,.06)   ← 半透明边框（关键！当前是实色 #2a2e3d）
--border-hover: rgba(255,255,255,.12)
--text-primary:   #F0F0F5
--text-secondary: #8888A0   ← 次要文字（带紫调）
--text-disabled:  #555566
--accent:       #3B82F6   ← 蓝（当前 sky-400 #38bdf8，改纯蓝）
--accent-hover: #5B9BF7
--accent-dim:   rgba(59,130,246,.15)
--success: #22C55E  --warning: #F59E0B  --danger: #EF4444  --info: #6366F1
```

### 排版
- 字体：`Inter` + `Noto Sans SC`（UI），`JetBrains Mono`（数据/参数）
- 字号 tokens：xs=12 / sm=13 / base=14 / lg=17 / xl=20 / 2xl=24
- 数据字号：data-sm=20 / data=28 / data-lg=36
- 间距：1=4 / 2=8 / 3=12 / 4=16 / 5=20 / 6=24 / 8=32
- 圆角：sm=6 / md=10 / lg=14 / full=9999
- 卡片阴影：`0 2px 8px rgba(0,0,0,.25)` + 内嵌高光 `inset 0 1px 0 rgba(255,255,255,.06)`

### 布局尺寸
- Topbar 高 56px（`--topbar-height`）
- TelemetryBar 高 44px
- StatusBar 高 32px（`--statusbar-height`），可折叠
- Sidebar 宽 72px（`--sidebar-width`，当前 68px）

## 实施步骤（共 6 步，约 14 个文件）

### Step 1 — 设计系统底座（index.css + index.html）
**`src/web/index.css`**：完全重写为真实 CSS 变量 + 全局基础样式 + Tailwind v4 `@theme` 映射，让 Tailwind 类（如 `bg-bg-secondary`、`text-accent`、`border-border`）可直接用，消除魔法值。
- 引入 Inter/JetBrains Mono/Noto Sans SC 字体栈
- 全局 reset、滚动条（6px，thumb `#ffffff1a`）、选区高亮
- 卡片基础类 `.mc-card`（border 1px + radius-lg + card-shadow + inset-highlight）
- 按钮 tokens：`.mc-btn-primary` / `.mc-btn-ghost` / `.mc-btn-danger`
- 保留 MicoAir range 滑块样式但用新 accent
- 动画：pulse / fadeIn / slideUp / scaleIn / spin

**`index.html`**：加 Google Fonts preconnect + link（Inter wght 400-700、JetBrains Mono 400-600、Noto Sans SC 400-700），更新 `<title>` 为 "MicoConfigurator"，加 `<meta name="color-scheme" content="light dark">`。

### Step 2 — 三层顶栏拆分（核心架构改动）
当前单层 `Header.tsx`（44px）拆为 3 个组件：

**`src/web/components/layout/Topbar.tsx`**（新建，56px）：
- 左：Logo（白底圆角小图）+ "MicoConfigurator" 标题 + 副标题 "PX4 飞控配置工具"
- 中：飞控信息（Board 徽章 mono 字体 / Autopilot / PX4 橙色徽章）
- 右：连接按钮（`.topbar__connect-btn`，断开时 `connect-pulse` 脉冲动画）+ 连接状态点 + 图标按钮组
- 点击连接按钮打开连接对话框

**`src/web/components/layout/TelemetryBar.tsx`**（新建，44px）：
- 实时遥测条，分组显示（每组用 1px 分隔线）：
  - ARMED/DISARMED 徽章（armed 红色脉冲 / disarmed 绿色）
  - 飞行模式 pill
  - Roll/Pitch/Yaw（mono 字体，带单位 °）
  - 高度/地速/航向（mono）
  - GPS fix 徽章（NoFix红/2D黄/3D绿/RTK蓝）+ 卫星数
  - 电池（图标+电压+百分比，颜色随电量 good/warn/crit）
  - EKF 状态点（可点开下拉显示 flags）
- 离线时整体 opacity:.5

**`src/web/components/layout/StatusBar.tsx`**（新建，32px，可折叠）：
- 收起态：最新一条飞控消息（severity 徽章 ERROR/WARNING/INFO + mono 文本 + 计数）
- 展开态：消息列表（向上弹出，最多 240px，带时间戳）
- 数据来自 store（新增 statuslog）

**`src/web/components/layout/Header.tsx`**：删除（被三者替代）。

**`src/web/App.tsx`**：布局改为 `.app` flex-col：
```
.app (flex-col h-screen)
  ├─ Topbar (56px)
  ├─ TelemetryBar (44px)
  ├─ .app__body (flex-1, flex-row)
  │   ├─ Sidebar (72px)
  │   └─ .app__main (flex-1, overflow-y-auto) → Routes
  └─ StatusBar (32px)
```

### Step 3 — 侧栏重做（Sidebar.tsx）
- 宽 72px，背景 `--bg-secondary`，右边框半透明
- 导航项：竖向 flex-col，图标 24px + 10px 标签，gap 2px
- 激活态：accent 文字 + accent-dim 背景 + 左侧 3px×20px accent 指示条（`::before`）
- 文案保持中文（连接/仪表盘/传感器/参数/电机/遥控器/手柄/飞行）
- 图标改用更精致的线性图标集（匹配原版 Lucide 风格）
- 底部连接指示灯保留并改色

### Step 4 — 连接页改为对话框模式
原 MicoConfigurator 用 **顶栏连接按钮 + 弹出对话框**（不是独立页面）。

**`src/web/components/ConnectDialog.tsx`**（新建）：
- 400px 宽对话框，`.connect-dialog` 类，overlay 毛玻璃背景
- Header（标题"连接飞控"+ 关闭 X）/ Body（类型切换 USB/蓝牙、端口 select、波特率 select、提示）/ Footer（取消 + 连接/断开按钮）
- 复用 ConnectionPage 全部逻辑（scanPorts/connect/disconnect）
- 由 Topbar 连接按钮 + Sidebar 连接状态点共同触发

**`src/web/pages/ConnectionPage.tsx`**：改为路由未连接时的占位/引导页（Logo + 提示"点击右上角连接"），或保留为 dialog 的容器。store 新增 `connectDialogOpen` 状态。

### Step 5 — 8 个页面内容样式统一
逐页把硬编码的 `bg-[#1c1f2b]`/`border-[#2a2e3d]`/`bg-[#12141c]`/`bg-[#242836]`/`bg-sky-500/15` 等替换为设计 token（CSS 变量或 `.mc-card` 类），保留所有功能逻辑、状态读取、事件处理、安全机制不变：

- **DashboardPage**：StatCard 用大字号 data tokens、`.tbar` 风格分组；AttitudeIndicator 容器用 `--att3d-canvas-bg` 渐变；传感器卡片用 `.mc-card` + 状态点
- **SensorPage**：左侧 tab 列表改 sidebar__item 风格；右侧校准卡片用 `.mc-card`；进度条用 success 色
- **ParameterPage**：用真实 `.params` 组件类（params__header / params__tree / params__group / params__row / params__value）——分组可折叠、行内编辑、mono 字体、modified 值标橙色
- **MotorPage**：电机布局卡片用 accent 色激活态；安全确认框用 danger-dim
- **ReceiverPage**：通道条用 mono 值 + accent 填充；校准块用 `.mc-card`
- **JoystickPage**：轴可视化用 accent；toggle 开关用 accent
- **FlightControlPage**：ARMED 横幅用 success/danger；飞行模式按钮用 accent-active；起飞高度 slider

### Step 6 — 子组件与全局收尾
- **AttitudeIndicator.tsx**：Canvas 背景改 `--att3d-canvas-bg` 渐变，无人机模型材质改 accent 色
- **RealtimeChart.tsx**：Recharts 配色改 chart-1~chart-8 tokens，Tooltip 用 `--bg-secondary`
- **EkfFusionPanel.tsx**：Toggle 改 accent 配色，用 `.mc-card`
- **stores/telemetryStore.ts**：新增 `statusLogs: StatusLog[]`（存飞控 statustext，最多 200 条），新增 `addStatusLog`
- **hooks/useWebSocket.ts**：`statustext` 消息改推入 statusLogs（当前只是 console.log）
- **stores/connectionStore.ts**：新增 `connectDialogOpen` + setter
- **public/favicon.svg**：可选更新为匹配的图标

## 验证方式
1. `npm run build` 通过（TS 无类型错误，Vite 产出 dist）
2. `npm run dev` 启动，浏览器对照 micoair.com/configurator 视觉比对：
   - 三层顶栏高度/配色/字体正确
   - 卡片边框为半透明而非实色
   - 强调色为纯蓝 #3B82F6 而非 sky-400
   - 数据用 JetBrains Mono
   - 连接对话框可弹出、扫描/连接功能正常
   - 8 个页面布局与原版对应页面一致
3. WebSocket / 遥测 / 解锁 / 电机测试 / 参数加载等功能**不受影响**（只改视觉，不动 store 接口和 WS 协议）

## 风险与边界
- **不动后端**（src/server/*）、**不动 shared/types.ts**、**不动 store 的对外接口**（仅内部新增字段）
- ReceiverPage 的假数据（Math.random）不在本次范围（保持现状）
- 字体在线加载：离线时回退系统字体（用户已确认接受）
- Leaflet 地图、3D 模型 .glb 等 HANDOVER.md 待办项不在本次范围
