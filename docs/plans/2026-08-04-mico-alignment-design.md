# 参数、状态与 PX4 终端对齐设计

## 目标与边界

本次改造对齐 MicoConfigurator 的三项核心交互：完整参数中文说明、分组状态变量与变化高亮、可输入命令的实时终端。实现仍遵守 OpenConfigurator 的本地优先和飞控栈隔离原则，不复制参考站代码，也不通过参数名推断 PX4/ArduPilot 身份。参数说明属于展示元数据，不能参与写权限判断；未知飞控与未实现的 ArduPilot 机型继续只读。

参数页采用“精确元数据优先、功能组保守说明兜底”的适配层。PID、EKF、飞控安装方向和常用电池参数复用已有配置定义或人工校对说明；其余参数根据飞控功能组和参数词元生成中文用途提示，并明确取值范围和生效方式以当前固件为准。搜索索引覆盖参数 ID、中文组名、标题和说明。

## 状态与数据流

状态页以 20 个标准组、192 个变量构成稳定目录。后端当前已经解码的数据填入对应变量；尚未收到或协议未提供的变量仍显示 `--`，避免把“未实现”误认为“不存在”。OpenConfigurator 原有的 IMU、原始磁场流、气压、光流、RC、执行器、固件和链路组作为扩展诊断继续保留。

前端以 500 ms 固定节拍读取 Zustand 快照，避免高频 MAVLink 帧直接驱动整棵变量树重渲染。每个变量使用 `group + name` 作为稳定键，比较连续快照并记录 1.1 秒高亮窗口。暂停时冻结快照并停止产生新高亮。消息页另保留每种 MAVLink 消息的最新解码字段、累计帧数、最后接收时间与实测频率。

## PX4 终端与安全

终端使用独立的 `shell_open`、`shell_write`、`shell_close`、`shell_output` 和 `shell_status` WebSocket 消息。服务端通过 MAVLink `SERIAL_CONTROL` 设备 10 连接 PX4 NuttX NSH，按 70 字节分片发送输入并转发输出；只有收到所选飞控的 DEV_SHELL 回包才进入已连接状态，无回包时在 2.5 秒后释放通道并报告固件能力不匹配。终端仅在目标已识别为 PX4、飞行器确认上锁、客户端持有控制权且参数/日志/ESC 会话空闲时开放；探测和活动会话期间拒绝其他 MAVLink 写操作。ArduPilot 不复用 PX4 Shell 通道。

验证覆盖运行时输入校验、SERIAL_CONTROL 开关/输入/输出、192 项目录、参数元数据、全量服务端测试、类型检查、生产构建，以及 Chrome 中的参数、状态高亮和终端安全状态检查。硬件无关测试不替代 PX4 实机终端 HIL 验证。
