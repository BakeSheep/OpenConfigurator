# ESC 参数兼容性

ESC 页面只配置 AM32 EEPROM 参数，不提供固件刷写或启动音编辑。下表区分“代码路径已实现”和“真实硬件已验证”；前者不构成安全或兼容性保证。

| 连接/设备 | 代码支持 | 实机证据（2026-07-30） |
|---|---|---|
| ArduPilot USB passthrough | 会话、MSP 245、4-way、断线恢复 | MicoAir743v2 / ArduCopter 4.7.0 已验证进入直通并识别 `0x1F06` |
| PX4 `SERIAL_CONTROL` 20–27 | 会话与字节传输 | 参数读取/写入待 HIL |
| USB 单线直连 19200 | 半双工字节传输 | 参数读取/写入待 HIL |
| AM32 `0x1F06` / `0x3506` / `0x1506` | EEPROM 定位、layout 1–3 解码与写后读回 | 完整写入验证待补充 |
| BLHeli_S / Bluejay / 未知设备 | 仅保守识别或只读 | 不支持参数写入 |

## 提升为实机支持的条件

- 正确识别 MCU、固件版本与 layout revision
- 完整读取 `0xB8` 字节并保存原始备份
- 单字段和批量写入均只改变目标字段，未知字节保持不变
- 每次写入后整块读回一致，断电重连后参数仍有效
- 多 ESC 单个失败不会继续制造“整批成功”
- 超时、掉线、WS 断开和取消不会继续写下一个目标
- 退出后 MAVLink/串口恢复，飞控可重新连接

新增实机证据时记录飞控板、飞控版本、ESC MCU/固件/layout、连接方式、日期、原始 EEPROM 和脱敏操作日志。发现回归时立即标为不可用。
