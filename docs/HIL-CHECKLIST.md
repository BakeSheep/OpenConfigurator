# HIL 实机验收清单

本清单必须在受控台架上执行。自动化测试、模拟 Web Serial 和协议 fixture 不能替代以下实机结果。所有电机/ESC 项目开始前拆除全部螺旋桨，准备独立断电手段并记录硬件、固件、浏览器和操作系统版本。

## 通用部署与隔离

- [ ] 两台电脑同时访问同一 HTTPS 地址，各自只看到并连接自己的本机设备。
- [ ] 静态站点访问日志只有 HTML/JS/CSS/资源 GET/HEAD，没有业务 API、WebSocket、飞控字节或日志上传。
- [ ] 刷新后只显示已授权端口，不自动打开；多个相同 VID/PID 设备要求重新选择。
- [ ] USB 拔出、端口占用、浏览器标签页关闭和显式断开均能安全结束会话。
- [ ] MAVLink signing 密钥在断开和刷新后消失，浏览器存储与日志中不存在密钥。

## PX4

- [ ] USB 串口：MAVLink v1、v2、auto 探测与波特率切换。
- [ ] 目标识别、参数全量同步、参数回显验证和未知机型只读门控。
- [ ] 加速度计、陀螺仪、磁罗盘、水平和气压计校准。
- [ ] armed 状态变化、模式切换、起飞/降落/RTL，以及不能仅凭 ACK 宣告成功。
- [ ] ULog 列表、乱序/重试下载、取消、保存、分析和消费后清理。
- [ ] NSH 终端打开、交互、关闭和断线清理。
- [ ] PX4 `SERIAL_CONTROL` AM32 路径：识别、读取、写入、整块读回和安全中止。

## ArduCopter

- [ ] HEARTBEAT profile 与 vehicle class 识别，其他 ArduPilot class 的写操作保持关闭。
- [ ] 参数同步、校准边界、飞行模式和 armed 状态门控。
- [ ] `MAV_CMD_DO_MOTOR_TEST` 使用 1-based motor instance，props-removed 门控生效。
- [ ] DataFlash 列表、下载、CRC/间隙恢复、取消、保存、分析和 artifact 清理。
- [ ] DataFlash erase 保留明确的“删除全部日志”确认。
- [ ] ArduPilot raw passthrough AM32 路径：静默窗口、MSP/4-way、完整读回和断线退出。

## Bluetooth Classic SPP

- [ ] Chrome 117+ 桌面环境通过系统已配对的 RFCOMM/SPP 设备连接。
- [ ] 短暂掉线只在当前标签页活动会话内进行有界重连。
- [ ] 显式断开后不再重连；端口被其他应用占用时给出可恢复错误。
- [ ] 低吞吐链路上的参数、遥测和日志背压不丢失高优先级停止/释放命令。

## 19200 波特直连 ESC

- [ ] 使用受支持单线适配器显式选择直连模式并切换到 19200 波特。
- [ ] AM32 MCU 与布局识别；未知签名拒绝写入。
- [ ] 参数修改保留未知 EEPROM 字节，完整写入块读回一致。
- [ ] 断电、拔线、取消和显式断开均退出会话，重新连接飞控时无残留原始字节。

## 记录

每次 HIL 记录至少包含：日期、执行人、电脑/操作系统、Chromium 版本、连接类型、飞控型号与固件、ESC 型号与固件、适配器、通过/失败项、日志或照片证据，以及失败后的安全状态。
